# Learn2Earn V5.0.0 发布说明

- 发布提交：以 `release-v5.0.0` 标签为准
- 发布分支：`release/v5`
- 不可移动标签：`release-v5.0.0`
- 基线：V4 `6034ffa`

## 已验收变更

1. 修复 Word 原图在产品编辑器中退化为 `[插图 N]` 文字的问题。产品页面根据关联笔记图片资产还原图片，保存时仍保留稳定插图锚点，DOCX 导出链路不受影响。
2. 兼容历史浏览器 Word 导入数据：若笔记正文含 `data:image/...;base64` 而资产表为空，首次查看产品或再次生成时按需提取并登记原图，不改写笔记正文。
3. 新导入 Word 的内嵌图在保存笔记后登记为 `NoteAsset`，避免后续生成丢图。
4. 产品生成中心明确说明：Word 原图可保留；底层大模型不生成新图片，纯文字材料只输出文字。
5. 生成任务卡片移除不准确的 Skill 数和算法数。
6. 产品类型 `ppt` 的对外显示名称统一改为“PPT大纲”，内部类型键保持不变，兼容历史数据。
7. 后端 API 版本固定为 `5.0.0`，新增 V5 独立启动器。

## 数据保护

V5 不删除或重建用户的科目、笔记、产品、Skill 与生成任务。针对目标存量笔记 `#62` 的迁移只新增 5 个图片资产，原笔记正文和产品均未改写。

## 验证门禁

- 图片锚点正反向回归测试通过。
- 后端完整测试 371 项通过。
- 前端回归测试 28 项通过。
- Python 编译检查与 Vite 生产构建通过。
- Playwright 浏览器验收通过：目标 SOP 产品已渲染 `word-image-1.jpg`；生成任务页不再出现 Skill/算法计数；产品库显示“PPT大纲”。
