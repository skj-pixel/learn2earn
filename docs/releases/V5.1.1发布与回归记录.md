# Learn2Earn V5.1.1 发布与回归记录

## 发布基线

- 基线：`release-v5.1.0` 后续启动器提交 `c27ec22`
- 修复分支：`bugfix/v5.1.1-rendering-prompts-counts`
- 发布标签：`release-v5.1.1`
- V5.1 保持冻结；本版本在独立 worktree、独立构建目录和独立数据目录中开发与运行。

## 已修复

1. 产品阅读页和 PDF 打印导出使用 KaTeX 渲染行内及块级 TeX 公式。
2. 每个 Mermaid 代码块在原位置独立渲染；删除整篇文章重复预览的实现方式。
3. 产品生成中心增加公共提示词，以及每种已选产品独立提示词；任务重试保留提示词。
4. 工作台笔记数和产品数采用与列表 API 相同的数据可见性规则，避免存量 `user_id` 数据导致统计不一致。
5. 固定版本启动器不切换主仓库分支，不复用已占用服务；代码来自固定 tag 的 detached worktree。
6. V5.1.1 首次启动复制数据库和 storage 为只读基线，再创建该版本专属可写运行副本，不修改 V5.1 数据。

## 人工验收重点

1. 包含 `$...$`、`$$...$$` 的产品正文和打印预览应显示排版后的公式。
2. 包含多个 Mermaid fence 的正文应逐块就地显示图表，页面底部不得出现整篇重复预览。
3. 同时选择两个产品，公共提示词应进入两种生成任务，各自提示词只能进入对应产品。
4. 工作台计数应与进入笔记列表和产品库后实际可见条目总数一致。
