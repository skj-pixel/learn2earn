# V5.1.3 统计与生成期间读取修复

## 基线

- 基线：`release-v5.1.2-history-restored.2`
- 分支：`bugfix/v5.1.3-stats-and-concurrent-read`
- V5.1.2 固定标签、代码、配置和数据库存储不修改。

## 修复内容

1. 工作台笔记数、产品数、草稿数、已发布数和金额均从同一份用户可见产品/笔记集合计算，避免列表与统计口径不一致。
2. 金额计算统一按数值转换，空值按 0 处理。
3. SQLite 启用 WAL、busy timeout 和只读重试，后台生成写入期间页面仍可读取最近一次已提交数据。
4. Skill 摘要查询纳入 SQLite 锁重试。
5. 产品、笔记列表请求失败时保留已有成功数据，不再把页面状态清空成空数组。
6. 产品生成中心使用 `Promise.allSettled`，Skill、策略、产品和建议请求互不连坐；部分请求繁忙时保留已加载内容并提示用户。

- 前端回归：35 项通过。
- SQLite WAL 并发读取测试：通过。
- Vite 生产构建：通过。
