# Learn2Earn V5.1.2 Memory Bear 可见性修复

## 基线与边界

- 基线标签：`release-v5.1.1`
- 修复分支：`bugfix/v5.1.2-memorybear-visibility`
- V5.1.1 的代码、构建、配置和数据保持冻结。
- 当前实现是本地确定性 Memory Bear 启发式引擎，不宣称等同于完整官方服务栈。

## 修复内容

1. 感知层从固定配额 0 改为 1，提取当前笔记标题、显式标签和学习阶段等可直接观察信号。
2. `meta.layers` 始终返回感知、工作、情景、显性、隐性五层，前端不再隐藏计数为 0 的层。
3. 修复路由结果依赖数组首项为工作记忆的隐患，改为按真实层类型生成标题。
4. 笔记侧栏改为“知识增强状态”，显示“Memory Bear 已启用”和“RAG 按需检索”。
5. 原“MB 权重”改为“路由建议”，明确百分比是启发式建议，不是本次真实检索用量。
6. 保持历史约束：不展示跨笔记记忆正文，避免误导和隐私混淆。

## 验证

- Memory Bear 后端专项：20 项通过。
- 前端回归测试：35 项通过。
- Vite 生产构建：通过（4558 modules transformed）。
