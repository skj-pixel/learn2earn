> 适用版本：F03 下架 8 种历史类型后，剩余 **14 种对外可生成产品类型**
> 目的：为每一种产品类型，从已打包的「知识付费 Skills 包」（`workbuddy_skills_all.zip`，72 个 skill）中，推荐 ≥1 个可直接用于生产该产品的技能。
> 配套产物：
> - 机器可读映射 `backend/bundled_skills/product_type_skill_map.json`
> - 运行时接口 `GET /api/skills/recommendations?product_type=<key>`
> - 单元测试 `backend/tests/test_skill_mapping.py`

## 2. 逐类型映射说明

### 1. `article` 技术文章/公众号推文
- **wechat-article-pro**：公众号深度长文（3000–5000 字）、AI 封面图、热搜搜集、刘润风格。
- **humanizer**：去除 AI 写作痕迹，避免文章被平台判为机器生成。
- **content-factory**：多 Agent 内容生产系统的 Writer 角色，可批量改写多平台版本。

### 2. `ppt` PPT
- **guizang-ppt-skill**：横向翻页网页 PPT（单 HTML），WebGL 背景 / 章节幕封 / 数据大字报 / 图片网格。
- **pptx-generator**：专业 .pptx 生成，11 种幻灯片类型、图表/表格/时间线，JSON 驱动、可编辑。

### 3. `sop` SOP流程文档
- **fbs-bookwriter**：长文档手稿利器，擅长手册 / SOP / 白皮书结构（S/P/C/B 分层审校）。
- **Word / DOCX**：产出可编辑 Word 版 SOP。
- **md-to-pdf-cjk**：带目录的中日韩 PDF，适合分发。

### 4. `prompt_template` AI提示词模板
- **skill-creator**：把提示词工作流封装成可复用 Skill 包。
- **self-improvement**：自我反思+迭代优化提示词效果。
- **Self-Improving + Proactive Agent**：记录错误/纠正、持续优化。

### 5. `course_outline` 课程大纲/教案
- **open-lesson**：Socratic 学习法，有向图学习计划 → 音频辅导 → 推理缺口分析。
- **teachany**：K-12 互动课件（课程页/动画/AI 导师/TTS/知识图谱）。
- **study-planner**：学习计划自动制定。

### 6. `interview_qa` 面试题库/答案解析
- **qa-expert**：擅长 QA / 测试题库与质量把控。
- **academic-tutor**：学术 / 技术题解析与辅导。
- **notebooklm-studio**：从内容直接批量生成测验。

### 7. `workflow` 工作流程图
- **knowledge-framework-builder**：知识 / 流程框架构建。
- **ontology**：类型化知识图谱（Person/Project/Task/Event/Document 实体）。
- **notion**：落地为看板 / 数据库。

### 8. `product_intro` 产品介绍/分销文案
- **ecommerce-copywriter**：电商爆款文案（淘宝/拼多多/抖音/京东标题+详情页+卖点）。
- **wechat-article-pro**：软件介绍带货软文。
- **promo-creator-skills**：60–90 秒产品宣传片总控。

### 9. `quiz` 自测题/练习题
- **notebooklm-studio**：从内容直接生成测验 / 练习题。
- **qa-expert**：控制题型与质量。
- **open-lesson**：分章节出题。

### 10. `mindmap` 知识思维导图
- **knowledge-framework-builder**：抽取概念层级。
- **notebooklm-studio**：生成思维导图。
- **ontology**：表达概念依赖关系。

### 11. `checklist` 行动清单/避坑指南
- **note-organizer**：笔记智能整理分类 → 要点清单。
- **task-alignment**：任务对齐与优先级。
- **plan-tracker**：计划跟踪管理。

### 12. `flashcard` 记忆卡片/Anki
- **notebooklm-studio**：直接产出闪卡。
- **obsidian**：卡片笔记库管理。
- **study-planner**：安排复习节奏（呼应艾宾浩斯曲线）。

### 13. `script` 视频脚本
- **content-factory**：Scriptwriter 角色写脚本。
- **content-repurposer**：长文 → 视频脚本片段。
- **gui-demo-video** / **remotion-video-toolkit**：录制成片（录屏+配音 / 程序化动画）。

### 14. `llm_skill` LLM Skill
- **skill-creator**：把工作流封装成 Skill 包。
- **self-improvement**：持续优化。
- **skill-vetter**：发布前安全审查。

## 5. 运行时使用

前端在用户选定产品类型后，调用：

```
GET /api/skills/recommendations?product_type=article
```

返回该类型推荐的已安装技能列表 + 覆盖缺口 `coverage_gap` / `missing_skills`，
可用于在生成配置页"推荐技能"区一键勾选，实现"选了产品类型 → 自动推荐对应技能"的闭环。
