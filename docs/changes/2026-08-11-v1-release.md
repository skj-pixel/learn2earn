# V1 发布前小修记录

日期：2026-08-11
分支：release/v1
状态：自动化验证通过，等待用户最终人工确认后打正式 release 标签。

## 变更

- 工作台移除左上角“学习科目”统计框，保留功能重复的学习笔记入口和科目概览。
- 笔记编辑器移除正文字符数统计及其错误的派生状态；保存仍直接读取 BlockNote 文档，不影响正文保存。
- 科目笔记列表增加带确认的删除按钮，删除后立即刷新列表和科目计数；未改变后端既有删除 API。
- LLM 配置提示中的 `GPT-4` 改为泛化的 `GPT`。
- Skills 仓库不再展示无意义的“知识产品”分类标签；分类字段仍保留在数据和搜索接口中。
- V1 启动脚本改为 ASCII BAT + PowerShell 启动器，分支切换和启动错误会停留显示，不再因中文脚本调用失败而闪退。
- 批量安装结果明确区分“处理的压缩包数量”和“跳过的重复 Skill 数量”。一个压缩包可含多个 Skill，因此重复 Skill 数超过压缩包数不再被错误解释为计数异常；每个压缩包保留明细。

## 数据保护

本轮未删除、重建、改名或清空任何用户科目、笔记、产品或 Skill。用户删除无用科目和上传的 Skill 数据保持现状。
