## 本轮修复

1. V1 启动脚本不再因为当前处于修复分支而静默退出。启动前会尝试切换到 `release/v1`；若 Git 因未提交冲突无法切换，会停止并给出明确处理提示。脚本不执行 stash、reset 或删除用户文件。
2. 从质量技术列表移除“迭代精炼”。迭代精炼仍保留为生成算法，避免策略页重复展示。
3. 生成任务 API 为任务补充科目、笔记标题和科目 ID；任务页展示科目、笔记和明确的 Skill/算法数量。
4. 为已完成或失败任务增加“重新生成”。重试会复制原任务的笔记、产品类型、目标产品和完整策略，创建新的任务记录，不修改旧任务历史。
5. 任务页对已完成任务提供按 `generation_meta.task_id` 过滤的对应产品入口，兼容覆盖已有产品的后台重新生成。
6. V1 笔记编辑器保留 MemoryBear 统计和权重摘要，但隐藏原始长期记忆全文，避免把跨笔记记忆细节误显示为当前笔记正文。官方 MemoryBear 集成不在 V1 中实施。
7. 产品生成中心的每产品策略 Skill 弹窗增加按 Skill 名称、摘要和分类搜索；服务端 Skill 查询同时支持摘要/说明字段。
